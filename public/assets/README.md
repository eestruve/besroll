## ⚡️ Как добиться 0 мс задержки при открытии:
1. Сохраните видеофайл или отрывок песни Беслана в формате `.mp4` прямо в эту папку с именем:
   `beslan.mp4`
   (Полный путь: `C:\Users\evgen\Desktop\Antigravity\NEWprodject\17_Бесроллинг\public\assets\beslan.mp4`)

2. **Как это работает:**
   * Страница использует нативный HTML5 плеер `<video>` с директивой `preload="auto"`.
   * Файл кэшируется браузером заранее.
   * При клике на кнопку приманки видео и звук стартуют **мгновенно без миллисекунды ожидания или буферизации**!
   * Если локальный файл отсутствует, плеер автоматически переключается на встроенный Instagram Embed.
