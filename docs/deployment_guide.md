# 🚀 Инструкция по бесплатному деплою проекта «Бесроллинг»

Чтобы ссылки-ловушки работали в Telegram, WhatsApp и VK, файлы из папки `public/` нужно опубликовать на любом бесплатном веб-хостинге. Ниже приведены 3 самых быстрых и надежных варианта.

---

## Вариант 1: GitHub Pages (100% бесплатно и навсегда)
*Лучший выбор, если у вас есть аккаунт GitHub.*

1. Создайте новый публичный репозиторий на GitHub (например, `besrolling` или `secret-leaks`).
2. Загрузите в него всё содержимое папки `public/` (файл `index.html` должен лежать в корне репозитория).
3. Перейдите в репозитории в **Settings** $\to$ **Pages**.
4. В поле **Source** выберите ветку `main` (папка `/ (root)`) и нажмите **Save**.
5. Через 1-2 минуты ваша ссылка будет доступна по адресу:  
   `https://ваш-ник.github.io/besrolling/` (или `.../gta6.html`, `.../tg_premium.html`).

---

## Вариант 2: Vercel (Деплой за 30 секунд без Git)
*Самый быстрый способ с возможностью привязать красивый бесплатный домен `.vercel.app`.*

1. Зайдите на [vercel.com](https://vercel.com) и авторизуйтесь.
2. Перетащите папку `public/` прямо в окно браузера в раздел **Add New... $\to$ Project**.
3. Назовите проект кликбейтно, например: `gta6-exclusive-leak` или `tg-premium-gift-2026`.
4. Нажмите **Deploy**.
5. Ваша ссылка будет выглядеть как:  
   `https://tg-premium-gift-2026.vercel.app/`

---

## Вариант 3: Netlify Drop (Деплой в 1 клик перетаскиванием)
1. Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку `public` в окно сайта.
3. Сайт моментально запустится и даст ссылку.

---

## 🔍 Как проверить превью ссылки перед отправкой другу:
* **Для Telegram:** Отправьте ссылку боту [@WebpageBot](https://t.me/WebpageBot), чтобы обновить кэш и увидеть превью.
* **Для VK:** Используйте инструмент [VK Link Debugger](https://vk.com/dev/pages.clearCache).
* **Для Facebook / WhatsApp:** [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/).
