# 👑 Проект: 17_Бесроллинг (Besrolling)

## 📌 Обзор проекта
**Бесроллинг (Besrolling)** — вирусный веб-проект и инструмент пранк-маркетинга, созданный для продвижения музыки и трека Беслана ([@besikraev](https://www.instagram.com/besikraev)). 
Проект повторяет легендарную механику **Рикролла (Rickrolling)** с использованием современных технологий: динамическая подмена OpenGraph-метатегов, интерактивные экраны-приманки (Bait-and-Switch), мгновенный автозапуск медиа и генератор ссылок-ловушек из любой новости.

---

## 🏗 Архитектура и стек
* **Фронтенд:** Чистый HTML5, CSS3 (Modern Glassmorphism, адаптив, живая карточка предпросмотра Telegram/WhatsApp), Vanilla JavaScript (Web Audio API, Canvas Confetti).
* **Netlify Edge Functions:** 
  * `/api/scrape` — серверный парсер метатегов с любого указанного пользователем URL (`og:title`, `og:image`, `og:description`).
  * `/r/*` — динамический маршрутизатор ловушек: подставляет для ботов мессенджеров фейковые метатеги новости, а для живых людей открывает интерактивный Бесролл и студию генератора в том же окне.
* **Интерактивный плеер:** Защита от блокировки автоплея браузерами (Click-to-Unmute / Instant Action Trigger), видео/аудио плеер с эффектом внезапного появления («You just got Beslaned!»).
* **Meme Studio (Генератор ловушек):** Встроенная панель создания ссылок (вставка любого URL новости + ручной редактор + готовые пресеты).
* **Хостинг и деплой:** Netlify + Netlify Edge Functions (бесплатно, 0 мс задержки, без внешней базы данных).

## 📁 Структура проекта
```
17_Бесроллинг/
├── PROJECT.md               # 🌟 Единый источник фактов о проекте
├── TASKS.md                 # 📋 Бэклог и статус задач
├── netlify.toml             # Конфигурация деплоя и маршрутизации Edge Functions
├── netlify/
│   └── edge-functions/
│       ├── scrape.ts        # Парсинг OpenGraph метатегов на лету
│       └── trap.ts          # Динамическая генерация HTML ловушек
├── docs/
│   ├── deployment_guide.md  # Инструкция по бесплатному деплою
│   └── meme_mechanics.md    # Сценарии и скрипты для вирусного посева
├── public/
│   ├── index.html           # Главная страница: плеер + генератор ссылок
│   ├── gta6.html            # Пресет-ловушка: Слив GTA 6
│   ├── tg_premium.html      # Пресет-ловушка: Подарок Telegram Premium
│   ├── gossip.html          # Пресет-ловушка: Личная интрига / Слив
│   ├── exam.html            # Пресет-ловушка: Ответы на экзамен / Документ
│   ├── css/
│   │   └── style.css        # Стили интерфейса, превью мессенджеров, анимации
│   └── js/
│       └── app.js           # Логика воспроизведения, парсера и генератора
└── scripts/
    ├── local_server.py      # Локальный сервер (симулятор Netlify Edge)
    └── import_video.py      # Утилита импорта видео
```
